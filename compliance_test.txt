📦 What you need to download / set up
Required (zero — everything else is included)
The zip is self-contained for the local-demo case. No external accounts, no API keys, no cloud sign-ups, no Docker, no Kafka, no databases. Just Python.
The one external thing you absolutely need:

Python 3.10, 3.11, or 3.12 — the code uses standard CPython

That's it for the bare minimum.
Step-by-step setup
bash# 1. Extract
unzip datashield_mtls_retraining__1_.zip
cd datashield

# 2. Install Python deps (one command, ~2 minutes)
pip install -r requirements.txt
This will pull in scikit-learn, xgboost, fastapi, uvicorn, pdfplumber, python-docx, shap, lime, cryptography, mlflow, evidently, and others — all from PyPI, no accounts needed.
bash# 3. Start the API + UI together
python run.py
If npm is on your PATH, this also auto-installs the React UI dependencies and starts the dev server. If you don't have npm, the API still works fine on its own — just use Swagger at http://localhost:8000/docs instead of the UI.
