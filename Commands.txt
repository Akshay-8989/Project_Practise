Ingestion Layer (ingestion.py)
What it does

Takes raw files and converts them into readable text.

Input
PDF
DOCX
TXT
CSV
JSON
HTML
Logs, etc.
Main tasks
Detect file type
Open file using correct parser
Extract text
Collect metadata (filename, file type, size)
Output
Raw extracted text + metadata
Purpose

Makes enterprise documents usable for NLP/ML models.

2. Preprocessing Layer (preprocessing.py)
What it does

Cleans and prepares the extracted text for machine learning.

Main tasks
Clean noisy text
Detect language (English/Hindi)
Mask sensitive data (PII)
Tokenize text into words
Split long text into chunks
Enrich metadata using business hints
Output
Structured NLP-ready document

Contains:

cleaned text
masked text
tokens
chunks
detected language
metadata
Purpose

Transforms messy human text into normalized structured data.

3. Feature Engineering Layer (feature_engineering.py)
What it does

Converts processed text into numerical ML features.

Main tasks
Generate TF-IDF features
Extract important keywords
Create n-gram statistics
Compute numeric features
Generate embedding statistics
Output
FeatureSummary object

Contains:

top keywords
token statistics
numeric signals
embedding info
Purpose

Transforms text into machine-readable numerical representations for models.

Simple End-to-End Flow
File Upload
    ↓
Ingestion
(extract text)
    ↓
Preprocessing
(clean + structure text)
    ↓
Feature Engineering
(convert to ML features)
    ↓
Models
(classification)
